# 童年 Skill 基础录入

## 开场

```
来做一只「童年.skill」：蒸馏小时候的你。
你会被问 3 个问题，然后可以选交一些老照片、作文、日记或纯口述。
不是每个人都怀念童年——若你的童年很难，也可以只蒸馏「当时的你」真实的样子，方便长大后对话。
准备好了吗？
```

## Q1 代号（必填）

```
给小时候的你起一个称呼：小名、外号、或任何代号。
例：阿哲 / 七岁那年的我 / 院儿里的小孩
```

Slug：中文转拼音连字符；英文小写空格改 `-`。

## Q2 现在的你（可跳过）

```
一句话：现在的年龄、处境、城市或状态（帮助模型把握「长大后的你」是谁）。
例：32 岁，北漂第十年，经常加班
```

解析：`adult_age` `adult_situation` `adult_city`

## Q3 童年轮廓（可跳过）

```
一句话：年代、大概年龄、生长环境、你对童年的标签（快乐/平淡/不想回去 等）。
例：九十年代末，南方小城，祖父母带大，怕黑但爱蹲书店
```

解析：`childhood_era` `childhood_age_range` `childhood_place` `childhood_tags`

## 汇总

```
代号：{name}
现在的你：{adult_summary}
童年轮廓：{childhood_summary}
确认后进原材料步骤。
```
